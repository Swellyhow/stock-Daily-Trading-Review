# 财联社新闻集成说明

本项目已将新闻数据源从东方财富快讯切换为财联社（CLS），以获得更高质量和更及时的新闻数据。

---

## 一、为什么使用财联社

### 优势

1. **新闻质量高** - 财联社是专业的财经资讯平台，新闻质量和时效性优于东方财富快讯
2. **更新及时** - 财联社电报页面实时更新，延迟通常在1分钟以内
3. **内容专业** - 专注于A股市场，新闻与题材催化高度相关
4. **去重可靠** - 基于内容哈希的去重机制，避免重复新闻

### 东方财富快讯的问题

1. **获取不稳定** - HTML解析容易失效，经常返回0条
2. **反爬虫严格** - 容易被识别和封禁
3. **质量参差** - 包含大量无关信息

## 二、财联社集成方案

### 架构设计

```
财联社监控项目 (独立运行)
    ↓
  SQLite数据库 (news.db)
    ↓
本项目财联社采集器 (读取数据库)
    ↓
  数据标准化
    ↓
  决策引擎
```

## 三、快速开始

### 步骤1：克隆财联社监控项目

```bash
# 克隆项目
git clone https://gitee.com/swallyhowl/cls.git

# 进入后端目录
cd cls/backend

# 安装依赖
npm install

# 安装Playwright浏览器（首次运行必需）
npx playwright install chromium
```

### 步骤2：配置环境变量

编辑 `cls/backend/.env` 文件，配置Silicon Flow API密钥：

```env
SILICON_FLOW_API_KEY=your_api_key_here
```

**获取API密钥**：访问 https://siliconflow.cn/ 注册并获取

### 步骤3：启动财联社监控

```bash
cd cls/backend
npm start
```

### 步骤4：链接数据库到本项目

```bash
# Windows
copy cls\backend\news.db A股游资\data\cls-news.db

# Linux/Mac
cp cls/backend/news.db A股游资/data/cls-news.db
```

### 步骤5：验证集成

访问原始数据查看器：http://localhost:3000/data-viewer.html

## 四、常见问题

### Q1：必须运行财联社监控项目吗？

**A**：是的。本项目只读取财联社数据库，不直接采集新闻。

### Q2：数据库文件在哪里？

**A**：
- 财联社项目：`cls/backend/news.db`
- 本项目：`data/cls-news.db`

### Q3：如何查看采集状态？

**A**：查看财联社监控项目的控制台输出，会显示采集进度和新闻数量。
