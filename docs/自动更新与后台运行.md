# 自动更新与后台运行

双击 `start-project.cmd` 启动项目，双击 `stop-project.cmd` 停止。停止状态会保存到本机，计划任务不会自动撤销手动停止；再次启动即可恢复。

## 后台服务

`scripts/project-service.ps1 -Mode Install` 注册当前 Windows 用户的 `HotMoneyTradingSystem` 任务：登录时启动，每分钟兜底检查，守护本身每 10 秒检查数据库、数据网页、策略看板和 CMES 桥接。服务异常退出后自动拉起，重复启动不会产生第二个守护。网页无需一直打开。计算机关机、休眠或该用户未登录时不能执行程序。

服务地址为 `http://localhost:3000/auction-monitor.html`，策略看板为 `http://localhost:3030/`。`/api/operations/status` 返回当前守护心跳、服务 PID、盘后任务执行结果和重试时间。日志位于 `data/runtime/`。

## 盘后任务

- 上海时间 15:30 开始保存当日涨停池。同花顺确定成员和交易日，已有详细数据源补充换手、封单等明细；缺少明细时保存可用内容并标记待重试。
- 15:50 后调用 stockdb 官方 `数据更新.exe` 下载公共行情，次日 00:30 后再检查最终数据。工作日 09:00 至 15:50 不运行公共文件更新，防止干扰交易期间读取。
- 16:00 开始获取同花顺复盘详细涨停原因。服务启动时补跑最近 7 个已结束交易日，已完成任务不会因重启重复执行。
- 失败按 15、30、60、120、240 分钟退避重试。公共更新、涨停池和复盘独立运行；慢速下载不阻塞复盘。
- 公共行情由官方更新器负责写入，项目随后确认沪市、深市、创业板、科创板多个样本的目标日 K 及收盘分钟数据可读取后，才标记成功。官方工具是托盘型 GUI，进程可能在写入完成后继续常驻，因此不把进程退出作为完成条件。上游未发布、数据库尚未加载新文件或非交易日，保留失败/待重试状态，不用旧数据充当成功。

更新使用官方工具，私有数据保留在 stockdb `mydb/`。不会自行移动 `data/`、`data1/` 或删除行情文件。每次任务只启动或复用同一路径的官方更新器，然后由 stockdb 查询校验决定成功；如果目标数据尚未可读，调度器会按退避策略重试，不会同时启动第二个更新器，也不会强行终止原更新器。
