### 3. ✅ 检查LLM配置状态

**检查结果**：

```
❌ SILICONFLOW_API_KEY: 未配置或为默认值
✅ SILICONFLOW_BASE_URL: 已配置
✅ SILICONFLOW_MODEL_PRIMARY: 已配置
✅ SILICONFLOW_MODEL_BACKUP: 已配置
```

**结论**：
- **LLM分析功能未启用**
- 原因：`SILICONFLOW_API_KEY` 未配置或为默认值 `your_api_key_here`
- 影响：无法进行新闻语义分析，叙事强度、可持续性、催化可信度等指标会降级为规则计算
- 系统行为：已实现完整降级机制，不会阻断主流程

**如何启用LLM分析**：

1. 编辑 `.env` 文件
2. 将 `SILICONFLOW_API_KEY=your_api_key_here` 改为实际API密钥
3. 获取API密钥：访问 https://api.siliconflow.cn/ 注册并获取
4. 重启服务

**LLM分析的作用**：
- 语义级别的新闻催化判断
- 评估催化事件类型（policy/announcement/industry-chain等）
- 评估情绪倾向（bullish/neutral/bearish）
- 评估持续性（medium/short/one-off）
- 计算叙事强度、叙事可持续性、催化可信度

### 财联社集成架构

**数据采集**（财联社监控项目）：
```
Playwright无头浏览器
    ↓
截图 + 图片对比
    ↓
AI提取（Kimi大模型）
    ↓
SQLite数据库（自动去重）
```

**数据读取**（本项目）：
```
cls-database.js (数据库接口)
    ↓
cls-collector.js (采集器)
    ↓
eastmoney-auto.js (集成)
    ↓
live-to-snapshot.js (标准化)
    ↓
决策引擎
```

## 注意事项

### 1. 财联社监控项目必须独立运行

本项目不直接采集财联社新闻，只读取数据库。必须先运行财联社监控项目。

### 2. 数据库文件路径

确保数据库文件在正确位置：
- 财联社项目：`cls/backend/news.db`
- 本项目：`data/cls-news.db`

### 3. LLM分析可选

LLM分析未启用时，系统会降级为规则引擎，不影响核心功能。

### 4. 定期维护

建议每周清理财联社数据库旧数据（保留7天）：
```bash
sqlite3 data/cls-news.db "DELETE FROM cls_news WHERE created_at < datetime('now', '-7 days'); VACUUM;"
```
