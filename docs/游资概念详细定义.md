# A股游资概念详细定义

本文档梳理项目中对游资交易核心概念的技术定义和判断标准。

---

## 一、龙头与核心股分类

### 1. 总龙头（Market Leader）

**定义**：当前市场辨识度最高、最能代表情绪方向的个股。

**判断标准**：
- `isLeader` 标记为 true，或
- 连板高度 ≥ 5板，或
- 综合评分与最高分差距 ≤ 10分

**评分权重**：
```javascript
score += boardHeight * 8           // 连板高度权重最高
score += recognition * 20          // 辨识度
score += auctionStrength * 15      // 竞价强度
score += reboundStrength * 15      // 反包强度
score += followThrough * 15        // 跟随性
score += volumeQuality * 10        // 量能质量
score += liquidityScore * 12       // 流动性
score += isLeader ? 15 : 0         // 龙头标记加分
score += 同主线 ? 10 : 0           // 主线题材加分
score -= isMidPositionRisk ? 15 : 0 // 中位风险扣分
```

**作用**：
- 对全市场情绪有锚定作用
- 它强，市场情绪容易稳
- 它倒，市场容易退潮

---

### 2. 题材龙头（Theme Leader）

**定义**：某个主线题材内地位最核心、最先启动、最能带板块的个股。

**判断标准**：
- 属于主线题材
- 连板高度 ≥ 3板
- 与同题材最高分差距 ≤ 15分

**特征**：
- 在题材内地位明确
- 带动板块联动
- 分歧时最容易被资金回流
- 跟风股经常看它脸色

---

### 3. 容量核心（Capacity Core）

**定义**：容量大、机构资金或大资金更容易参与的核心股。

**判断标准**：
- 属于主线题材
- 流动性评分 ≥ 0.65
- 辨识度 ≥ 0.55
- 量能质量 ≥ 0.45

**特征**：
- 不一定最高板
- 但有容量、有影响力
- 能稳住板块
- 往往是趋势核心

**意义**：中军强，说明题材不是纯情绪瞎炒，而是有更强资金介入。

---

### 4. 中军（Mid Army）

**定义**：主线题材内具有一定容量和影响力的支撑性个股。

**判断标准**：
- 属于主线题材
- 流动性评分 ≥ 0.55
- 辨识度 ≥ 0.45

---

### 5. 前排核心（Front Runner）

**定义**：主线题材内处于前排位置的核心个股。

**判断标准**：
- 属于主线题材
- 连板高度 ≥ 2板
- 与同题材最高分差距 ≤ 25分

---

### 6. 中位跟随（Mid Follower）

**定义**：主线题材内的中位跟随股。

**判断标准**：
- 属于主线题材
- 连板高度 ≥ 2板
- 但不满足前排核心条件

**风险**：中位股在退潮期最容易大面积补跌。

---

### 7. 低位补涨（Low Position Catch-up）

**定义**：主线题材被确认后，低位相关股开始跟随上涨。

**判断标准**：
- 属于主线题材
- 连板高度 ≤ 1板
- 辨识度 ≥ 0.35

**特征**：
- 启动晚于龙头
- 逻辑依附主线
- 弹性可能很强
- 但地位弱于龙头和核心

**注意**：补涨可以做，但一定要知道——补涨不是龙头。补涨一旦脱离主线支持，死得很快。

---

### 8. 后排跟风（Back Runner）

**定义**：非主线题材但有一定质量的跟风股。

**判断标准**：
- 不属于主线题材
- 辨识度 ≥ 0.45
- 流动性评分 ≥ 0.45

---

### 9. 杂毛（Junk）

**定义**：没有地位、没有辨识度、没有带动性的个股。

**特征**：
- 跟风但没地位
- 没辨识度
- 没带动性
- 涨的时候你觉得像机会
- 跌的时候没人管

**警告**：短线亏钱，很多时候不是因为买错了龙头，而是因为把杂毛当成了核心。

---

## 二、题材分类与判断

### 1. 主线题材（Primary Theme）

**定义**：市场最愿意持续投入的方向。

**判断标准**（mainlineScore ≥ 7，满足以下至少7项）：
- ✓ 持续性 ≥ 2天
- ✓ 排名前2
- ✓ 有龙头
- ✓ 梯队完整（不足/一般/完整）
- ✓ 梯队结构评分 ≥ 0.48
- ✓ 龙头带动评分 ≥ 0.45
- ✓ 假突破风险 ≤ 0.5
- ✓ 中位风险 ≤ 0.58
- ✓ 赚钱效应 ≥ 0.5
- ✓ 次日溢价 ≥ 0.45
- ✓ 回流能力 ≥ 0.45
- ✓ 叙事可持续性 ≥ 0.45

**特征**：
- 有明确催化
- 有龙头
- 有板块梯队
- 有容量核心
- 有持续赚钱效应
- 分歧后还能回流

**梯队结构**：
```
龙头数/前排数/中位数/低位数/容量数
```

---

### 2. 支线/过渡题材（Secondary Theme）

**判断标准**：mainlineScore 在 5-6 分之间。

**特征**：
- 有一定热度
- 但持续性弱于主线
- 可能只是轮动补充
- 板块内部不够完整

**理解**：支线可以做，但只能辅助，不适合重仓上头。

---

### 3. 一日游/弱题材（One-day Wonder）

**判断标准**：mainlineScore < 5 分。

**特征**：
- 盘中突然爆发
- 第二天没有持续性
- 没有龙头、没有梯队、没有回流
- 更多是消息刺激

**理解**：一日游题材最容易让人冲动追高，第二天挨打。

---

### 4. 题材评分体系

```javascript
score += continuityDays * 10              // 持续天数
score += limitUpCount * 2                 // 涨停家数
score += maxBoardHeight * 4               // 最高板高度
score += hasLeader ? 15 : 0               // 有龙头
score += hasMidCap ? 8 : 0                // 有中军
score += profitEffect * 18                // 赚钱效应
score += nextDayPremiumScore * 16         // 次日溢价
score += comebackStrength * 14            // 回流能力
score += linkageStrength * 18             // 联动强度
score += newsCatalystStrength * 15        // 新闻催化
score += narrativeStrength * 14           // 叙事强度
score += narrativeSustainability * 12     // 叙事可持续性
score += catalystCredibility * 10         // 催化可信度
score += structureScore * 20              // 梯队结构
score += leaderDriveScore * 12            // 龙头带动
score -= falseBreakoutRisk * 10           // 假突破风险
score -= midRiskScore * 8                 // 中位风险
```

## 三、情绪周期阶段

### 1. 冰点（Freezing Point）

**环境评分**：≤ 25分

**特征**：
- 跌停较多
- 高位股集体杀
- 连板高度下降
- 炸板率高
- 昨日强股没溢价
- 情绪极差

**动作**：
- 以观察为主
- 小仓试错新方向
- 不做高位接力
- 重点等修复信号

---

### 2. 修复/启动（Recovery）

**环境评分**：26-45分

**特征**：
- 冰点后开始有强势股站出来
- 跌停减少
- 首板、二板开始出现
- 核心股不再一砸就死
- 市场开始出现主动进攻意愿

**动作**：
- 轻仓参与新题材前排
- 重视弱转强和首个修复核心
- 不追太后排

---

### 3. 震荡轮动（Oscillation）

**环境评分**：46-59分

**特征**：
- 市场处于中性状态
- 没有明确的主线或退潮信号
- 赚钱效应分散

---

### 4. 进攻环境/发酵（Attack Mode）

**环境评分**：≥ 60分（进攻环境）或 ≥ 75分（强进攻）

**特征**：
- 主线明确
- 板块扩散
- 龙头继续加强
- 前排持续晋级
- 次日有较强溢价
- 赚钱效应好

**动作**：
- 可以主动做主线核心
- 可以做前排换手板
- 可以提高仓位
- 只聚焦最强方向

---

### 5. 高潮（Climax）

**特征**：
- 全市场都在讲同一个题材
- 前排普遍加速
- 后排大量补涨
- 涨停很多
- 一致性极强

**理解**：看起来最热闹，但其实风险开始变大。因为一致以后，很容易次日分歧兑现。

**动作**：
- 有先手的人舒服
- 没先手的人谨慎追高
- 开始准备分歧预案
- 后排不值得去接

---

### 6. 分歧/退潮（Divergence/Retreat）

**特征**：
- 龙头震荡加大
- 后排先掉队
- 中位股开始补跌
- 昨日强股反馈变差
- 炸板率升高
- 连板晋级率下降

**动作**：
- 降低仓位
- 只做核心，不做跟风
- 不及预期立即走
- 退潮明确时尽量空仓

---

## 四、弱转强（Weak-to-Strong）

### 定义

**弱转强**：原本市场预期今天会弱，结果竞价超预期或盘中明显更强，说明有超预期资金进来。

### 本质

弱转强的本质是**预期差**。

### 判断标准（代码中的体现）

在 `execution.js` 中，弱转强作为允许的买点之一：

```javascript
if (
  (market.yesterdayStrongFeedback ?? 0) >= 0.2 &&  // 昨日强股反馈 ≥ 0.2
  environment.score >= 50 &&                        // 环境评分 ≥ 50
  ["容量趋势抱团", "主线低吸回流"].includes(modeProfile.primaryMode)  // 模式匹配
) {
  allowedSetups.push("核心股弱转强");
}
```

### 适用场景

- 容量趋势抱团模式
- 主线低吸回流模式
- 环境不能太差（≥50分）
- 昨日强股有一定正反馈

---

## 五、题材爆发（Theme Outbreak）

### 定义

题材从启动到发酵的过程，表现为：
- 涨停家数快速增加
- 板块联动增强
- 龙头地位确立
- 梯队快速形成

### 判断维度

1. **新闻催化强度**（newsCatalystStrength）
   - 有明确催化事件
   - 逻辑能讲得通
   - 有想象空间

2. **联动强度**（linkageStrength ≥ 0.6）
   - 不是一只票涨停
   - 有首板、有连板、有趋势核心、有中军助攻

3. **赚钱效应**（profitEffect ≥ 0.5）
   - 前一天参与的人，第二天有正反馈

4. **次日溢价**（nextDayPremiumScore ≥ 0.45）
   - 昨日涨停股次日高开高走
   - 昨日连板股继续晋级

5. **回流能力**（comebackStrength ≥ 0.45）
   - 分歧后还能回流
   - 不是一天热闹

### 爆发阶段识别

- **启动期**：mainlineScore 5-6分，题材刚开始被认可
- **发酵期**：mainlineScore ≥ 7分，题材成为主线
- **高潮期**：涨停家数多、一致性强、后排补涨
- **退潮期**：龙头分歧、后排掉队、赚钱效应变差

## 六、市场风格偏好

### 1. 连板接力（Relay Trading）

**判断条件**：
- 连板接力赚钱效应评分 ≥ 0.55
- 最高板高度 ≥ 4板
- 连板数量 ≥ 6个
- 强溢价占比 ≥ 0.35
- 风格差 ≥ 0.2（小票占优）
- 成长指数涨幅 ≥ 0.2%

---

### 2. 容量趋势（Capacity Trend）

**判断条件**：
- 容量趋势赚钱效应评分 ≥ 0.52
- 成长指数涨幅 ≥ 0.25%
- 大盘指数涨幅 ≥ -0.1%
- 成长风格差 ≥ -0.2%

---

### 3. 低吸修复（Low Absorption）

**判断条件**：
- 低吸赚钱效应评分 ≥ 0.5
- 深负反馈占比 ≥ 0.12
- 昨日强股反馈 ≥ 0.15

---

### 4. 首板套利（First Board Arbitrage）

**判断条件**：
- 首板赚钱效应评分 ≥ 0.45
- 最高板高度 ≤ 2板
- 强溢价占比 < 0.25

---

### 5. 防守轮动（Defensive Rotation）

**判断条件**：以上条件都不满足时的默认状态。

---

## 七、关键买点类型

### 1. 龙头分歧转一致

**条件**：
- 环境评分 ≥ 50
- 有主线题材
- 主线联动强度 ≥ 0.6
- 当前模式为"连板接力"或"容量趋势抱团"

**特征**：
- 开盘或盘中先分歧
- 但承接很好
- 分歧后再次转强
- 板块跟着回流

---

### 2. 前排换手板确认

**条件**：
- 有主线题材
- 主线联动强度 ≥ 0.6
- 当前模式为"连板接力"或"容量趋势抱团"

**特征**：
- 属于主线前排
- 不是一字买不到
- 有换手、有承接
- 上板质量高

---

### 3. 核心股弱转强

**条件**：
- 昨日强股反馈 ≥ 0.2
- 环境评分 ≥ 50
- 当前模式为"容量趋势抱团"或"主线低吸回流"

---

### 4. 主线回流低吸

**条件**：
- 有主线题材
- 主线回流能力 ≥ 0.5
- 主线次日溢价 ≥ 0.45
- 当前模式为"主线低吸回流"或"容量趋势抱团"

---

### 5. 冰点后首个修复核心

**条件**：
- 情绪阶段为"启动"或"冰点"
- 当前模式为"首板消息套利"或"主线低吸回流"

## 八、环境评分计算

```javascript
score = 50  // 基准分

// 正向因子
score += (limitUpCount - 40) * 0.7           // 涨停家数
score += (maxBoardHeight - 2) * 4            // 连板高度
score += (mainlineConcentration - 0.3) * 35  // 主线集中度
score += yesterdayStrongFeedback * 20        // 昨日强股反馈
score += avgYesterdayPremiumPct * 1.2        // 昨日平均溢价
score += (strongPremiumRatio - 0.3) * 20     // 强溢价占比
score += (resonanceScore - 50) * 0.25        // 指数共振

// 负向因子
score -= (limitDownCount - 5) * 1.2          // 跌停家数
score -= (brokenBoardRate - 0.2) * 40        // 炸板率
score -= highPositionNegativeFeedback * 20   // 高位负反馈
score -= deepNegativeRatio * 18              // 深负反馈占比

// 限制在 0-100 范围
score = clamp(score, 0, 100)
```

## 九、关键指标说明

### 1. 昨日强股反馈（yesterdayStrongFeedback）

衡量昨天最强的一批股票今天的表现：
- 高开还是低开
- 冲高后有没有承接
- 能不能继续给溢价

### 2. 次日溢价（nextDayPremiumScore）

昨日涨停股次日的平均溢价表现。

### 3. 回流能力（comebackStrength）

主线题材分歧后能否再次回流、重新走强的能力。

### 4. 联动强度（linkageStrength）

板块内个股的联动程度，是否形成合力。

### 5. 炸板率（brokenBoardRate）

涨停板炸板的比例，反映承接力。

### 6. 强溢价占比（strongPremiumRatio）

昨日强股中次日溢价较高的占比。

### 7. 深负反馈占比（deepNegativeRatio）

昨日强股中次日大幅低开或大跌的占比。

## 十、实战应用逻辑

### 每日判断流程

1. **判断情绪阶段**：冰点/修复/震荡/进攻/退潮
2. **识别主线题材**：是否有 mainlineScore ≥ 7 的题材
3. **定位龙头核心**：总龙头、题材龙头、容量核心
4. **判断市场风格**：连板接力/容量趋势/低吸修复/首板套利/防守轮动
5. **确认允许买点**：根据环境和模式，确定当前允许的买点类型
6. **仓位控制**：根据情绪阶段和环境评分，决定仓位大小

### 风险控制原则

- 不做非主线、非核心、非计划内交易
- 中位股在退潮期最危险
- 杂毛永远不值得重仓
- 该强不强就是弱，立即止损
- 龙头或核心股不及预期，按计划减仓或清仓
