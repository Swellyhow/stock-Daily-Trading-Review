- `name` - 股票名称
- `latestPrice` - 最新价格
- `changePct` - 涨跌幅
- `amount` - 成交额
- `turnoverPct` - 换手率
- `boardCount` - 连板天数
- `firstLimitTime` - 首次涨停时间（格式：HHMMSS）
- `lastLimitTime` - 最后涨停时间
- `sealAmount` - 封单金额
- `brokenCount` - 炸板次数
- `industry` - 所属行业
- `stats` - 统计信息

**用途**：
- 识别当日涨停股票
- 计算连板高度
- 判断龙头、题材龙头、容量核心
- 分析板块联动强度
- 评估封单强度和炸板率
- 构建题材梯队结构

**重要性**：★★★★★（缺失会导致系统无法运行）

### 3. 昨日涨停池数据（Previous Limit-Up Pool）

**数据来源**：
- 东方财富公开接口：`https://push2ex.eastmoney.com/getYesterdayZTPool`

**包含字段**：
- `code` - 股票代码
- `name` - 股票名称
- `changePct` - 今日涨跌幅（次日溢价）
- `boardCount` - 昨日连板天数
- `amount` - 今日成交额
- `turnoverPct` - 今日换手率
- `industry` - 所属行业

**用途**：
- 计算昨日强股反馈（yesterdayStrongFeedback）
- 计算次日溢价（nextDayPremiumScore）
- 评估赚钱效应（profitEffect）
- 计算强溢价占比（strongPremiumRatio）
- 计算深负反馈占比（deepNegativeRatio）
- 判断题材持续性和回流能力
- 构建四大赚钱效应模式（连板接力、容量趋势、低吸修复、首板套利）

**重要性**：★★★★★（缺失会导致赚钱效应无法计算）

**计算逻辑**：
```javascript
// 昨日强股反馈
yesterdayStrongFeedback = 
  positiveRatio * 0.5 +           // 正溢价占比
  strongPremiumRatio * 0.3 +      // 强溢价占比（≥3%）
  premiumScore * 0.2              // 综合溢价评分

// 次日溢价评分
nextDayPremiumScore = 
  positiveRatio * 0.45 +          // 正溢价占比
  strongPremiumRatio * 0.35 +     // 强溢价占比
  premiumScore * 0.2              // 综合溢价评分

// 强溢价占比
strongPremiumRatio = count(changePct ≥ 3%) / total

// 深负反馈占比
deepNegativeRatio = count(changePct ≤ -5%) / total
```

## 二、增强数据需求（强烈推荐）

### 5. 市场指数数据（Market Indices）

**数据来源**：
- 东方财富指数行情接口：`https://push2.eastmoney.com/api/qt/stock/get`
- 东方财富K线接口：`https://push2his.eastmoney.com/api/qt/stock/kline/get`

**包含指数**：
- 上证指数（1.000001）
- 深证成指（0.399001）
- 创业板指（0.399006）
- 沪深300（1.000300）
- 国证2000（0.399303）
- 科创50（1.000688）

**包含字段**：
- `latestPrice` - 最新价格
- `prevClose` - 昨收价
- `changePct` - 涨跌幅
- `changeAmount` - 涨跌额
- `amplitudePct` - 振幅
- `volume` - 成交量
- `amount` - 成交额
- `latestHistoryAmount` - 今日历史成交额
- `previousHistoryAmount` - 昨日历史成交额

**衍生指标**：
- `indexChangePct` - 大盘综合涨跌幅（上证+深成平均）
- `growthIndexChangePct` - 成长指数涨跌幅（创业板指）
- `totalTurnoverBn` - 两市总成交额（亿元）
- `turnoverDeltaPct` - 成交额变化率
- `largeCapIndexChangePct` - 大盘股指数涨跌幅（沪深300）
- `smallCapIndexChangePct` - 小盘股指数涨跌幅（国证2000）
- `styleSpreadPct` - 风格差（小盘 - 大盘）
- `growthSpreadPct` - 成长差（创业板 - 沪深300）

**用途**：
- 判断市场风格偏好（小票/大票/均衡）
- 计算指数共振评分
- 评估量能状态（放量/缩量）
- 判断市场模式（连板接力/容量趋势/防守轮动）
- 计算环境评分

**重要性**：★★★★☆（缺失会降低风格判断准确度，但不阻断主流程）

**计算逻辑**：
```javascript
// 风格差
styleSpreadPct = smallCapIndexChangePct - largeCapIndexChangePct

// 风格判断
if (styleSpreadPct > 0.8%) → 小票风格
if (styleSpreadPct < -0.8%) → 大票风格
else → 均衡风格

// 量能状态
turnoverDeltaPct = ((today - yesterday) / yesterday) * 100
if (turnoverDeltaPct > 15%) → 放量
if (turnoverDeltaPct > 5%) → 温和放量
if (turnoverDeltaPct > -5%) → 平量
else → 缩量
```

### 11. LLM新闻语义分析数据（LLM News Analysis）

**数据来源**：
- SiliconFlow API + DeepSeek-V3.2模型
- 输入：新闻标题列表 + 题材名称列表

**输出字段**：
- `themeCatalysts` - 题材催化列表
  - `theme` - 题材名称
  - `isCatalyst` - 是否有催化
  - `strength` - 催化强度（0-1）
  - `eventType` - 事件类型（policy/announcement/industry-chain/earnings/flow/general/none）
  - `sentiment` - 情绪倾向（bullish/neutral/bearish）
  - `duration` - 持续性（medium/short/one-off）
  - `reason` - 催化原因（简短）
  - `detailedReason` - 详细原因
  - `decisionImpact` - 决策影响
  - `riskNote` - 风险提示
  - `headlineIds` - 相关新闻ID列表
- `relevantNewsCount` - 相关新闻数量
- `rejectedNews` - 被拒绝的新闻列表
- `warning` - 警告信息（如果LLM失败）

**用途**：
- 提供语义级别的催化判断
- 评估催化事件类型和持续性
- 计算叙事强度（narrativeStrength）
- 计算叙事可持续性（narrativeSustainability）
- 计算催化可信度（catalystCredibility）
- 提供决策影响和风险提示

**重要性**：★★☆☆☆（增强催化判断，但失败时会降级为规则判断）

**计算逻辑**：
```javascript
// 事件类型权重
eventTypeWeight = {
  policy: 1.0,
  announcement: 0.92,
  "industry-chain": 0.88,
  earnings: 0.82,
  flow: 0.5,
  general: 0.35,
  none: 0
}

// 情绪权重
sentimentWeight = {
  bullish: 1.0,
  neutral: 0.55,
  bearish: 0.2
}

// 持续性权重
durationWeight = {
  medium: 1.0,
  short: 0.9,
  "one-off": 0.72
}

// 加权LLM催化强度
llmBoost = strength * eventTypeWeight * sentimentWeight * durationWeight

// 催化可信度
catalystCredibility = 
  (isCatalyst ? 0.45 : 0) +
  min(headlineIds.length / 3, 0.25) +
  mxCatalystBoost * 0.3

// 叙事强度
narrativeStrength = llmBoost * 0.7 + mxCatalystBoost * 0.3

// 叙事可持续性
narrativeSustainability = 
  narrativeStrength * 0.45 +
  durationWeight * 0.3 +
  min(continuityDays / 3, 1) * 0.25
```

```

   ├─ fetchEastmoneyMarketState(date)
   │  ├─ 涨停池
   │  ├─ 跌停池
   │  ├─ 昨日涨停池
   │  ├─ 概念板块
   │  ├─ 快讯
   │  └─ 市场指数
   │
2. 妙想数据增强（可选）
   ├─ fetchMxDecisionContext(state)
   │  ├─ 新闻搜索
   │  ├─ 股票筛选
   │  └─ 市场查询
   │
3. LLM语义分析（可选）
   ├─ analyzeNewsCatalysts(news, themes)
   │  └─ 返回题材催化分析
   │
4. 盘中微观结构（可选，仅盘中模式）
   └─ fetchEastmoneyIntradayMicrostructure(limitUpPool, watchNames)
```

### 数据转换流程

```
原始数据 (Raw Market State)
   ↓
buildSnapshotFromLiveMarketState()
   ↓
标准化快照 (Normalized Snapshot)
   ├─ market: 市场整体数据
   ├─ themes: 题材列表（含催化、梯队、溢价）
   ├─ stocks: 股票列表（含评分、角色）
   ├─ dataQuality: 数据质量评估
   └─ liveContext: 原始上下文
   ↓
normalizeRawInput()
   ↓
决策引擎输入
```

### 关键数据转换

**题材构建**：
```javascript
buildThemes(limitUpPool, previousLimitUpPool, conceptBoards, mxContext, newsAnalysis)
```

## 五、数据质量评估

系统会自动评估数据质量并输出 `dataQuality` 对象：

```javascript
{
  confidence: 0.85,              // 数据置信度（0-1）
  warnings: [],                  // 警告列表
  requestedTradeDate: "20260415", // 请求的交易日
  resolvedTradeDate: "20260415",  // 实际使用的交易日
  isFallbackTradeDate: false,    // 是否使用回退日期
  estimatedFields: {}            // 估算字段标记
}
```

### 置信度计算规则

**基准分**：0.85

**扣分项**：
- 涨停池为空：-0.45
- 昨日涨停池为空：-0.15
- 概念板块缺失：-0.15
- 新闻催化缺失：-0.10
- 指数数据缺失：-0.08
- 未形成有效题材：-0.20
- 核心股候选过少：-0.10
- 使用回退交易日：-0.18
- 每个妙想警告：-0.03（最多-0.12）
- LLM分析降级：-0.03
- 每个估算字段：-0.02（最多-0.12）

**加分项**：
- 有妙想新闻：+0.03
- 有妙想筛选：+0.04
- 有LLM催化分析：+0.05
- 有被拒绝新闻：+0.01

### 决策闸门

根据 `confidence` 自动降级：

- `confidence < 0.45`：**hard-stop**，输出"停止出手/空仓"
- `0.45 ≤ confidence < 0.60`：**cautious**，只允许保守结论
- `confidence ≥ 0.60`：正常决策

## 六、数据缺失降级策略

### 1. 妙想数据缺失

**影响**：
- 新闻催化强度降低
- 容量核心识别准确度下降
- 题材叙事评估保守

**降级策略**：
- 使用东方财富快讯替代
- 使用行业聚合替代概念板块
- 催化强度按0处理
- 置信度降低0.1-0.2

---

### 2. LLM分析失败

**影响**：
- 无法提供语义级催化判断
- 叙事强度、可持续性、可信度降级

**降级策略**：
- 使用规则引擎替代
- 基于新闻标题关键词匹配
- 催化强度基于妙想统计
- 置信度降低0.03

---

### 3. 指数数据缺失

**影响**：
- 无法准确判断市场风格
- 量能状态无法计算
- 指数共振评分缺失

**降级策略**：
- 风格判断保守处理
- 环境评分降低权重
- 置信度降低0.08

---

### 4. 昨日涨停池缺失

**影响**：
- 昨日强股反馈无法计算
- 次日溢价无法评估
- 赚钱效应无法判断

**降级策略**：
- 使用弱近似值（0.5）
- 禁止主动进攻
- 置信度降低0.15

---

### 5. 涨停池为空

**影响**：
- 主线判断完全失效
- 龙头识别无法进行
- 题材梯队无法构建

**降级策略**：
- 输出"停止出手/空仓"
- 置信度降低0.45
- 触发hard-stop闸门

## 七、数据更新频率

### 盘前模式（daily-md / auto-live）
- 运行时机：盘前或盘后
- 数据时效：T日收盘后数据
- 更新频率：每日一次

### 盘中模式（intraday-live）
