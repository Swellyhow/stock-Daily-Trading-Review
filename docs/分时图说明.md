# 分时图数据说明

## 数据格式

### 什么是分时图？
分时图显示股票在交易日内的价格走势，是投资者最常用的实时行情图表之一。

### 数据频率
- **1分钟级别**：每分钟一个数据点
- **交易时间**：
  - 上午：09:30-11:30（120分钟）
  - 下午：13:00-15:00（120分钟）
  - 总计：240个数据点/天

### 数据内容
每个数据点包含：
- `time`: 时间（如 "09:30", "09:31"）
- `price`: 当前价格（该分钟的最新成交价）
- `avgPrice`: 均价（从开盘到当前时刻的成交均价）
- `volume`: 成交量（该分钟的累计成交量）
- `preClose`: 昨收价（用于计算涨跌幅）
- `changePct`: 涨跌幅（相对昨收价的百分比）

### 图表展示
1. **价格线**（蓝色）：连接每分钟的价格点，显示价格波动
2. **均价线**（黄色）：显示当日平均成交价格走势
3. **成交量柱**（底部）：显示每分钟的成交量

### 与K线图的区别
| 特性 | 分时图 | K线图 |
|------|--------|-------|
| 时间范围 | 当日实时 | 历史多日 |
| 数据点 | 每分钟价格 | 每根K线（开高低收） |
| 图表类型 | 折线图 | 蜡烛图 |
| 用途 | 盘中实时监控 | 趋势分析 |

## API接口

### 获取分时数据
```
GET /api/minute?code=000001
```

**参数**：
- `code`: 股票代码（必填）

**返回示例**：
```json
[
  {
    "code": "000001",
    "name": "平安银行",
    "time": "09:30",
    "price": 11.05,
    "volume": 125000,
    "avgPrice": 11.05,
    "preClose": 11.00,
    "changePct": 0.45
  },
  {
    "time": "09:31",
    "price": 11.06,
    "volume": 248000,
    "avgPrice": 11.055,
    "changePct": 0.55
  }
  // ... 更多数据点
]
```

## 注意事项

1. **交易时间限制**：分时数据只在交易时间内更新，收盘后API返回空数组
2. **数据延迟**：实时数据可能有几秒到几分钟的延迟
3. **停牌股票**：停牌股票无分时数据
4. **集合竞价**：09:15-09:25的集合竞价阶段数据需使用竞价API获取

## 使用示例

### 在图表页面查看
1. 打开 http://localhost:3000/chart-viewer.html
2. 输入股票代码（如 000001）
3. 选择"分时图"
4. 点击"加载图表"

### 命令行测试
```bash
# 获取平安银行分时数据
curl "http://localhost:3000/api/minute?code=000001"

# 获取贵州茅台分时数据
curl "http://localhost:3000/api/minute?code=600519"
```

## 技术实现

### 数据源
- 东方财富 trends2 API
- 端点：`https://push2.eastmoney.com/api/qt/stock/trends2/get`

### 前端渲染
- 使用 ECharts 折线图
- 双Y轴布局（价格 + 成交量）
- 实时tooltip显示涨跌幅

### 数据处理
```javascript
// 解析trends2 API返回的数据
const trends = payload.data.trends; // ["09:30,125000,11.05,11.05", ...]
trends.map(line => {
  const [time, volume, price, avgPrice] = line.split(',');
  return { time, volume, price, avgPrice };
});
```
