# A股游资数据获取功能清单

## 已实现的数据获取功能

### 1. 市场状态数据 (`fetchEastmoneyMarketState`)
**数据来源**: 东方财富网
**获取内容**:
- ✅ 涨停池 (limitUpPool) - 当日所有涨停股票
  - 股票代码、名称、最新价、涨幅
  - 封单金额、换手率、板数
  - 首次涨停时间、最后涨停时间
  - 打开次数、所属行业
- ✅ 跌停池 (limitDownPool) - 当日所有跌停股票
- ✅ 昨日涨停池 (previousLimitUpPool) - 昨日涨停股票今日表现
- ✅ 概念板块 (conceptBoards) - 热门概念板块
  - 板块代码、名称、涨幅
  - 主力净流入
  - 龙头股及其涨幅
- ✅ 市场指数 (marketIndices) - 主要指数行情
  - 上证指数、深证成指、创业板指
  - 沪深300、科创50、国证2000
  - 成交额、涨跌幅、振幅等
- ✅ 财联社新闻 (clsNews) - 从本地数据库获取

**API端点**: `/api/raw-data`
**Web界面**: http://localhost:3000/data-viewer.html

### 2. 个股分时数据 (`fetchStockTrend`)
**数据来源**: 东方财富网
**获取内容**:
- ✅ 分时价格走势 (每分钟数据点)
  - 时间戳、价格、均价
  - 成交量、成交额
- ✅ 分时技术指标
  - 开盘动能、收盘相对均价
  - 回撤控制、支撑强度
  - 盘中弱势风险评分

**使用场景**: 盘中微观结构分析 (`fetchEastmoneyIntradayMicrostructure`)

### 3. K线历史数据 (`fetchIndexDailyAmounts`)
**数据来源**: 东方财富网
**获取内容**:
- ✅ 指数日K线数据
  - 日期、成交额
  - 用于计算成交额变化

**当前限制**: 仅用于指数成交额对比，未完整导出个股K线功能

### 4. 个股实时行情 (`fetchQuoteSnapshot`)
**数据来源**: 东方财富网
**获取内容**:
- ✅ 实时价格、涨跌幅
- ✅ 成交量、成交额
- ✅ 振幅、换手率

**使用场景**: 配合分时数据进行微观结构分析

### 5. 新闻数据
#### 5.1 东方财富新闻搜索 (`fetchEastmoneyArticleSearch`)
- ✅ 关键词搜索新闻
- ✅ 支持分页、排序

#### 5.2 东方财富快讯 (`fetchEastmoneyFastNews`)
- ✅ 实时快讯抓取

#### 5.3 财联社新闻 (通过本地数据库)
- ✅ 从SQLite数据库读取
- ✅ 支持关键词搜索
- ✅ 支持时间范围筛选

**API端点**: `/api/search`
**Web界面**: 
- http://localhost:3000/search.html (搜索)
- http://localhost:3000/news-list.html (列表)

### 2. 个股完整K线历史 ❌
**说明**: 个股的日K、周K、月K数据
**需要获取**:
- 开盘价、收盘价、最高价、最低价
- 成交量、成交额、换手率

**实现方案**:
```javascript
// 已有API接口，需要封装导出
async function fetchStockKline(code, period = 'daily', limit = 100) {
  const secid = stockSecId(code);
  const klt = period === 'daily' ? 101 : period === 'weekly' ? 102 : 103;
  
  const payload = await fetchJson(
    "https://push2his.eastmoney.com/api/qt/stock/kline/get",
    {
      secid,
      klt,
      fqt: 1, // 前复权
      lmt: limit,
      fields1: "f1,f2,f3,f4,f5,f6",
      fields2: "f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61",
      ut: "fa5fd1943c7b386f172d6893dbfba10b",
      _: Date.now()
    }
  );
  
  return payload?.data?.klines ?? [];
}
```
