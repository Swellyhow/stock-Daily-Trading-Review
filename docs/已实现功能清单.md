## 🎯 使用建议

### 日常使用流程

1. **每日收盘后 (15:30)**
   ```bash
   node sync-data.js daily-task
   ```

2. **补充历史数据**
   ```bash
   node sync-data.js sync-recent 30
   ```

3. **查看同步状态**
   ```bash
   node sync-data.js status
   ```

4. **启动Web服务**
   ```bash
   node web/search-server.js
   ```

5. **查询数据**
   - 浏览器访问: http://localhost:3000/api/history/sync-status
   - 或使用API接口查询具体数据

### 定时任务配置

**Windows任务计划程序:**
- 每个交易日15:30执行: `node sync-data.js daily-task`
- 每个交易日9:22执行: `node sync-data.js auction-task`
- 每周日凌晨2点执行: `node sync-data.js maintenance`
