# 涨停类型量化定义与字段说明

> 文档状态：待审核方案
>
> 本文档只定义字段口径和计算规则，不修改页面、不写入生产计算逻辑。用户审核通过后，再按本文档实现，并用历史样本回测阈值。

## 1. 目标与原则

“涨停类型”不是同花顺接口直接提供的字段，而是根据同花顺日线、实时行情和分时明细计算的派生字段。计算结果必须区分：

- `confirmed`：输入完整、涨停价口径明确，规则满足；
- `unknown`：数据缺失、市场状态异常或多个类型分数接近，不能可靠判断；
- `not_applicable`：当日未确认涨停，不计算涨停类型。

炒股场景优先保证不误导：宁可显示“未知”，也不使用缺失数据强行分类。页面显示名称可以是“一字板”等，但数据层同时保存 `typeCode`、`confidence`、`evidence`、`calculatedAt` 和 `ruleVersion`，以便追溯。

## 2. 页面字段字典

### 2.1 板块信息

| 字段 | 定义 | 口径/注意事项 |
|---|---|---|
| 序号 | 当前列表中的展示序号 | 由当前排序结果从 1 开始生成，不作为数据主键。 |
| 板块名称 | 同花顺概念板块名称 | 概念板块，不是行业板块；保留同花顺原始名称。 |
| 涨幅 | 板块指数相对前收盘的涨跌幅 | 使用同花顺板块实时行情；单位为 %。 |
| 涨家数 | 板块内上涨股票数量 | 必须标注统计时点和同花顺板块成分快照。 |
| 跌家数 | 板块内下跌股票数量 | 同上；停牌/平盘股票不计入涨跌家数。 |
| 涨停数 | 板块内被判定为涨停的股票数量 | 展示口径应固定为“板块实时摘要”或“按本地个股明细重算”，两者不能混用；建议同时保留 `sourceCount` 与 `recomputedCount`。 |
| 跌停数 | 板块内被判定为跌停的股票数量 | 与涨停数采用同一口径。 |
| 最低价时间 | 板块分时价格达到当日最低值的最早时间 | 以板块分时序列为准；相同最低值取最早时间。 |
| 最高价时间 | 板块分时价格达到当日最高值的最早时间 | 相同最高值取最早时间。 |
| 起涨时间 | 分时中“上涨分钟”成交量最大的时间 | 上涨分钟定义为本分钟价格高于上一有效分钟价格；不是最低价时间。 |
| 起跌时间 | 分时中“下跌分钟”成交量最大的时间 | 下跌分钟定义为本分钟价格低于上一有效分钟价格。 |
| 板块新闻 | 板块相关新闻 | 当前留空；后续接入财联社时必须记录来源、发布时间和原文链接。 |

### 2.2 个股信息

| 字段 | 定义 | 口径/注意事项 |
|---|---|---|
| 序号 | 当前个股列表展示序号 | 随筛选、排序结果重新编号。 |
| 个股名称 | 股票简称 | 同花顺股票名称；ST 前缀必须保留。 |
| 涨幅 | 最新价相对前收盘的涨跌幅 | 单位为 %，收盘后使用收盘价。 |
| 现价 | 最新成交价 | 盘中为最新价，收盘后为收盘价；应同时保存采集时间。 |
| 主力金额 | 同花顺行情中的主力资金金额 | 不得用成交额或其他来源金额替代；无可靠字段时显示“未知”。 |
| 换手率 | 当日成交股数/流通股本 | 单位为 %，采用同花顺实时字段。 |
| 上市交易所 | 股票市场分类 | 按代码和证券状态映射为深A主板、沪A主板、创业板、科创板、京A等；代码推断必须允许人工修正。 |
| 最低价时间 | 分时价格达到当日最低值的最早时间 | 不是“起涨时间”。 |
| 最高价时间 | 分时价格达到当日最高值的最早时间 | 相同最高值取最早时间。 |
| 起涨时间 | 上涨分钟中成交量最大的时间 | 价格上升且该分钟成交量为有效分钟成交量；若接口返回累计量，先做差分。 |
| 起跌时间 | 下跌分钟中成交量最大的时间 | 价格下降且成交量最大；无有效下跌分钟则未知。 |
| 涨停时间 | 当日第一次触及涨停价的时间 | 以分时价格和已计算涨停价判断，不能只看接口标签。 |
| 跌停时间 | 当日第一次触及跌停价的时间 | 同上。 |
| 流通市值 | 可流通股份数 × 最新价 | 单位建议统一为元，展示时再格式化为万/亿。 |
| 总市值 | 总股本 × 最新价 | 单位建议统一为元。 |
| 概念板块起涨时间 | 当前概念板块的起涨时间 | 必须指明对应板块和计算日期，避免跨板块复用。 |
| 涨停类型 | 根据日线和分时特征计算的形态分类 | 仅对确认涨停股票计算；不满足可靠性门槛显示“未知”。 |
| 股票新闻 | 个股相关新闻 | 当前留空；后续接入时保留来源和发布时间。 |

### 2.3 辅助元数据（不一定直接展示）

建议每条计算结果附带：`tradeDate`、`source`、`sourceFetchedAt`、`intradayPointCount`、`typeCode`、`confidence`、`evidence`、`ruleVersion`、`dataQuality`。这些字段用于审计，不应被 UI 格式化丢失。

## 3. 输入数据与统一预处理

### 3.1 必需输入

日线/实时字段：

```text
prevClose, open, high, low, close, latestPrice,
limitPrice, turnoverPct, volume, amount, changePct, marketType, name, code
```

分时明细按时间升序排列，每点至少包含：

```text
{ tradeDate, time, price, volume, amount }
```

若接口给的是累计成交量，先转换为分钟成交量：

```text
minuteVolume[i] = max(0, cumulativeVolume[i] - cumulativeVolume[i - 1])
```

若无法确认量字段是累计量还是分钟量，`dataQuality` 标为 `volume_ambiguous`，不得使用需要量能的分类规则给出高置信度结果。

### 3.2 交易时间

- 正常交易：09:30-11:30、13:00-15:00。
- 09:15-09:25 集合竞价不作为连续竞价形态；若未来接入集合竞价数据，单独保存，不混入本规则。
- 主板 15:00 后的数据过滤掉。
- 科创板、创业板、京A可存在 15:00 后固定价格交易；这部分不参与“炸板、封板速度、盘中回撤”等连续竞价特征，除非明确标记为盘后数据。
- 分时点排序、去重；缺失超过 10 分钟或有效点少于 30 个时，形态结果默认 `unknown`。

### 3.3 涨停价与价格精度

涨停比例 `R` 的初始规则：

| 股票类别 | `R` |
|---|---:|
| 普通主板（沪A/深A） | 10% |
| ST、*ST、S*ST | 5% |
| 创业板 | 20% |
| 科创板 | 20% |
| 京A | 30% |

涨停价按交易所最小变动价位取整。优先使用接口明确提供的涨停价；没有时才按前收盘和 `R` 计算。价格比较容忍度 `epsilon` 初始为一个最小价位（通常 0.01 元），不得使用固定百分比代替价格精度。

以下情况不直接分类：新股上市前若干交易日、除权除息导致前收盘不可比、停牌复牌、证券简称/市场类别无法确认、涨停比例疑似临时调整。

### 3.4 涨停确认

```text
isLimitUp = close >= limitPrice - epsilon
             或分时中至少一个有效点 price >= limitPrice - epsilon
```

收盘未封住但盘中曾触及涨停的股票，仍可计算“盘中触板形态”，但展示字段应另存 `limitUpStatus = touched_not_closed`，不把它伪装成收盘涨停类型。本文十类“涨停板”默认要求收盘价确认封板。

分时封板状态：

```text
sealed(i) = price[i] >= limitPrice - epsilon
broken(i) = price[i] <  limitPrice - epsilon
```

连续封板区间允许最多一个缺失点；缺失点超过一个按炸板处理并降低数据质量。

## 4. 分时特征定义（中文说明）

为了让规则可以复核，系统先从日线和分时中提取以下“事实”，再根据事实打标签：

| 特征 | 中文含义 |
|---|---|
| 开盘高低 | 开盘价比昨收高出或低出的幅度。 |
| 日内振幅 | 当天最高价与最低价之间的波动幅度。 |
| 首次触板时间 | 分时价格第一次达到涨停价的时间。 |
| 最后回封时间 | 最后一次炸板后重新封住涨停的时间。 |
| 炸板次数 | 触及涨停后又跌离涨停价，再重新触板的次数。连续缺失一个分时点不单独算炸板。 |
| 炸板时长 | 所有触板后没有封住涨停的分钟数。 |
| 回封后封板时长 | 最后一次回封到收盘之间保持涨停的分钟数。 |
| 触板前最大回撤 | 第一次触板前，价格从阶段高点回落的最大幅度。 |
| 全日最大回撤 | 当天任意高点之后出现的最大回落幅度。 |
| 量能放大 | 当天成交量相对近 20 个交易日平均水平的放大程度。 |
| 换手放大 | 当天换手率相对近 20 日中位数的放大程度。 |
| 上涨最大量时间 | 价格比上一有效分钟上涨的分钟中，成交量最大的时间，也就是“起涨时间”。 |
| 下跌最大量时间 | 价格比上一有效分钟下跌的分钟中，成交量最大的时间，也就是“起跌时间”。 |
| 接近涨停后的回踩 | 价格达到涨停价九成五附近后，重新回落的幅度。 |
| 走势直线程度 | 首次触板前，大多数分时点是否持续抬高，期间回调是否很少。 |
| 横盘时间和范围 | 一段时间内价格波动很小、但没有继续上涨的持续时间和幅度。 |
| 上升波段数 | 通过高点、低点识别出的连续上涨段数量。 |

图片中的阈值以“该股票适用的涨跌幅限制”为基准。普通主板通常为10%，创业板和科创板通常为20%，京A通常为30%；若股票是ST等特殊状态，必须使用当天实际适用的涨跌幅限制。所有“距离涨停2%”“达到涨跌幅限制的一半”等描述，都先换算成价格，再与分时价格比较。

## 5. 涨停类型量化规则（按图片定义）

以下类型是**可叠加标签**，不是互相排斥的单选项。例如一只股票可以同时命中“高开秒板”和“直线板”。图片中没有定义烂板、N字板、偷袭尾盘板，因此本版本不为这三类擅自增加判定条件，后续另行补充。

只有收盘确认封住涨停的股票才使用“涨停板”标签；盘中触板但收盘未封住的股票显示“盘中触板”，不归入以下类型。

### 5.1 一字板

先确认开盘价、最高价、最低价和收盘价都在涨停价附近，再检查开盘价到收盘价之间的K线实体偏离涨停价的幅度。主板实体偏离不超过涨跌幅限制的1%（通常约1个百分点），创业板和科创板不超过2%（通常约2个百分点），京A不超过3%（通常约3个百分点）。同时，分时中不能出现超出该允许范围的有效下探、明显上下影线或打开涨停。全部满足才标记一字板。

### 5.2 T字板：浅T板和深T板

T字板先满足一字板的主体条件：开盘、收盘都在涨停价附近，K线主体很小；盘中曾经打开涨停并下探，之后重新回到涨停附近。用“涨停价向下到当天最低价的距离”与当天涨跌幅限制比较：下探幅度不超过涨跌幅限制一半，标记浅T板；下探幅度达到或超过涨跌幅限制一半，标记深T板。下探后没有重新封住涨停，只能标记盘中触板，不能标记T字板。

### 5.3 高开秒板

开盘价相对昨收的涨幅达到当天涨跌幅限制的一半或以上。例如普通主板至少高开约5%，创业板和科创板至少高开约10%，京A至少高开约15%。从09:30连续竞价开始计算，必须在5分钟内封住涨停，封板后直到收盘不能再次打开。开盘已接近涨停且全天无下探时，可同时命中一字板。

### 5.4 直线板

在分时中寻找连续3分钟的快速拉升区间。以这3分钟开始时的价格为起点，结束时必须达到涨停价；这3分钟内完成的上涨幅度至少达到当天涨跌幅限制的70%。例如普通主板3分钟至少上涨约7个百分点，创业板和科创板至少上涨约14个百分点。达到涨停后还必须收盘封板，盘中触及后回落只能记录快速触板。

### 5.5 换手板

同时满足两项：第一，开盘价相对昨收的涨跌幅绝对值在当天涨跌幅限制的一半以内，例如普通主板不超过约5%，创业板和科创板不超过约10%，京A不超过约15%；第二，当天换手率大于或等于30%。最后确认收盘价达到涨停价附近，才标记换手板。

### 5.6 阶梯推升板

封住涨停之前，至少出现2段相互独立的“上涨后横盘整理”。每段横盘至少持续15分钟，横盘期间振幅不超过1.5%；横盘结束后的下一段拉升幅度在2%-4%之间；每一级的高点逐步抬高，不能跌回前一级平台以下；最后一段拉升达到并封住涨停。只有一段连续上涨、没有至少两段横盘整理，不标记阶梯推升板。

### 5.7 地天板

先找到当天分时最低价。最低价距离跌停价不超过2个百分点，才进入候选。例如普通主板跌停限制为-10%，最低涨跌幅达到-8%或更低即满足；创业板、科创板和京A按各自限制换算。随后，从这个接近跌停的最低价开始，必须在3分钟内拉升到距离涨停价不超过2个百分点的位置；普通主板即至少拉到+8%或更高。收盘价也必须距离涨停价不超过2个百分点。三个条件全部满足才标记地天板。

## 6. 多标签、置信度与不确定结果

### 6.1 每种类型独立判断

系统对图片定义的八个标签逐一判断（一字板、浅T板、深T板、高开秒板、直线板、换手板、阶梯推升板、地天板），不设置互斥优先级。每种类型都输出：

- 是否命中：是/否；
- 置信度：高/中/低，或 0-100 分；
- 命中的事实依据，例如“高开 6.2%”“09:33 首次封板”“炸板 3 次”；
- 未满足的关键条件；
- 可能同时命中的其他类型。

### 6.2 建议的置信度规则

- 必要条件全部满足，且辅助特征大部分满足：高置信度；
- 必要条件满足，但分时点缺失、成交量口径不确定或辅助特征不足：中置信度；
- 只有部分现象符合，或关键数据缺失：低置信度；
- 关键价格、涨停价或分时数据缺失：未知，不输出具体类型。

本版本不再强制使用统一的总分排名。每个标签只要图片中的必要条件全部满足即可命中；如果数据缺失或只满足部分条件，显示“条件部分满足”或“未知”。后续如需增加置信度，可在不改变必要条件的前提下，用历史样本校准。

### 6.3 页面展示建议

“涨停类型”字段建议展示为多个标签，例如：

```text
高开秒板 · 直线板
```

点击标签时显示命中的时间、回撤、炸板次数、量能和置信度。未涨停显示“--”；已触板但未封板显示“盘中触板”；数据不足显示“未知”。

## 7. 数据质量与异常处理

以下任一情况出现时，类型应为 `unknown` 或降低置信度：

- 分时有效点少于 30 个，或连续缺失超过 10 分钟；
- 无法确认分钟成交量是否为增量；
- `prevClose/open/high/low/close/limitPrice` 任一关键价格缺失；
- 交易时间之外的数据未能正确剔除；
- 复权、除权除息或新股上市造成价格基准不可比；
- 同花顺实时摘要与本地重算结果不一致；
- 个股被标记为停牌、临时停牌或交易状态异常。

涨停池接口可能有自己的统计排除项（例如 ST 是否纳入与页面口径不同），因此：

- 板块摘要涨停数、官方涨停池数量、本地按分时重算数量必须分开存储；
- “涨停类型”以个股价格规则和分时为准，不以涨停池是否返回该股票作为唯一依据；
- 页面展示数量时必须带上口径标签和统计时间。
