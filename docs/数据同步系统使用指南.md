# 市场数据同步系统使用指南

## 概述

已实现完整的市场数据获取、存储和查询系统，支持：
- ✅ 个股K线历史数据
- ✅ 涨停池/跌停池历史
- ✅ 概念板块历史
- ✅ 市场指数历史
- ✅ 竞价数据
- ✅ 增量更新机制
- ✅ Web API接口

## 数据库结构

数据库文件：`src/data/market.db`

### 数据表

1. **stock_kline** - 个股K线数据
2. **limit_up_history** - 涨停池历史
3. **limit_down_history** - 跌停池历史
4. **sector_history** - 板块历史
5. **index_history** - 指数历史
6. **auction_data** - 竞价数据
7. **sync_log** - 同步日志

## 数据同步

### 1. 手动同步

#### 同步今日市场数据
```javascript
import marketSync from './src/lib/collector/market-sync.js';

// 同步涨停池、跌停池、板块、指数
const result = await marketSync.syncDailyMarketData();
console.log('同步结果:', result);
```

#### 同步个股K线数据
```javascript
// 单只股票
const result = await marketSync.syncStockKline('000001', {
  period: 'daily',  // daily/weekly/monthly
  limit: 100,       // 获取数量
  incremental: true // 增量更新
});

// 批量同步
const codes = ['000001', '000002', '600000'];
const result = await marketSync.syncBatchStockKline(codes, { limit: 100 });
```

#### 同步涨停池股票的K线
```javascript
// 自动同步某日涨停池所有股票的K线数据
const result = await marketSync.syncLimitUpStockKline('2026-04-26', { limit: 100 });
```

#### 增量同步最近N天
```javascript
// 同步最近7天的数据
const results = await marketSync.syncRecentDays(7);
```

#### 同步竞价数据
```javascript
// 注意：只在交易日 9:15-9:25 期间有效
const result = await marketSync.syncAuctionData();
```

### 2. 使用调度器

```javascript
import scheduler from './src/lib/collector/market-scheduler.js';

// 执行每日同步任务（建议收盘后15:30执行）
await scheduler.dailySyncTask();

// 执行竞价同步任务（建议9:20-9:25执行）
await scheduler.auctionSyncTask();

// 执行增量同步（补充历史数据）
await scheduler.incrementalSyncTask(7);

// 数据库维护
await scheduler.maintenanceTask();

// 查看同步状态
const status = scheduler.getSyncStatus();
console.log(status);
```

### 3. 定时任务配置

使用系统cron或Windows任务计划程序：

#### Linux/Mac (crontab)

# 每个交易日9:22执行竞价同步
22 9 * * 1-5 cd /path/to/project && node -e "import('./src/lib/collector/market-scheduler.js').then(m => m.auctionSyncTask())"

# 每周日凌晨2点执行维护
0 2 * * 0 cd /path/to/project && node -e "import('./src/lib/collector/market-scheduler.js').then(m => m.maintenanceTask())"

## Web API接口

服务器地址：http://localhost:3000

### 实时数据

#### 获取当前市场数据
```
GET /api/raw-data
```
返回：涨停池、跌停池、板块、指数、财联社新闻

### 历史数据

#### 1. K线历史数据
```
GET /api/history/kline?code=000001&limit=100
GET /api/history/kline?code=000001&start=2026-01-01&end=2026-04-26
```

参数：
- `code` (必需): 股票代码
- `limit`: 返回数量，默认100
- `start`: 开始日期 YYYY-MM-DD
- `end`: 结束日期 YYYY-MM-DD

#### 2. 涨停池历史
```
GET /api/history/limit-up?date=2026-04-26
GET /api/history/limit-up?start=2026-04-01&end=2026-04-26
GET /api/history/limit-up?date=2026-04-26&code=000001
```

参数：
- `date`: 查询单日数据
- `start` + `end`: 查询日期范围
- `code`: 可选，筛选特定股票

#### 3. 跌停池历史
```
GET /api/history/limit-down?date=2026-04-26
```

#### 4. 板块历史
```
GET /api/history/sector?date=2026-04-26
GET /api/history/sector?start=2026-04-01&end=2026-04-26
GET /api/history/sector?date=2026-04-26&code=BK0001
```

#### 5. 指数历史
```
GET /api/history/index?date=2026-04-26
GET /api/history/index?date=2026-04-26&code=1.000001
```

#### 6. 竞价数据
```
GET /api/history/auction?date=2026-04-26
```

#### 7. 交易日列表
```
GET /api/history/trading-dates?limit=100
```

#### 8. 同步状态
```
GET /api/history/sync-status
```

返回各类数据的最后同步时间和数据库统计信息。

### 场景5：个股技术分析
```javascript
import marketDatabase from './src/lib/collector/market-database.js';

// 获取某股票最近100天K线
const klines = marketDatabase.getStockKline('000001', null, null, 100);

// 计算均线
function calculateMA(klines, period) {
  const closes = klines.map(k => k.close);
  const ma = [];
  for (let i = 0; i < closes.length; i++) {
    if (i < period - 1) {
      ma.push(null);
    } else {
      const sum = closes.slice(i - period + 1, i + 1).reduce((a, b) => a + b, 0);
      ma.push(sum / period);
    }
  }
  return ma;
}

const ma5 = calculateMA(klines, 5);
const ma10 = calculateMA(klines, 10);
const ma20 = calculateMA(klines, 20);

console.log('MA5:', ma5[0]);
console.log('MA10:', ma10[0]);
console.log('MA20:', ma20[0]);
```

## 数据维护

### 清理过期数据
```javascript
import marketDatabase from './src/lib/collector/market-database.js';

// 删除1年前的K线数据
const oneYearAgo = new Date();
oneYearAgo.setFullYear(oneYearAgo.getFullYear() - 1);
const cutoffDate = oneYearAgo.toISOString().slice(0, 10);

marketDatabase.db.prepare('DELETE FROM stock_kline WHERE date < ?').run(cutoffDate);
console.log('已清理1年前的K线数据');
```

## 性能优化建议

1. **批量同步**：使用 `syncBatchStockKline` 而不是循环调用 `syncStockKline`
2. **增量更新**：启用 `incremental: true` 只同步新数据
3. **限制数量**：合理设置 `limit` 参数，避免一次获取过多数据
4. **错误重试**：网络错误时自动重试，避免数据缺失
5. **定期维护**：每周执行一次 `maintenanceTask` 优化数据库
