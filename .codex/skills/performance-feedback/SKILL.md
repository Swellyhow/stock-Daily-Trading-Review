# Performance Feedback

Use this skill when actual trade results need to be folded back into the system.

## Workflow

1. Read outcome input JSON.
2. Normalize trade and summary fields.
3. Generate an outcome review.
4. Archive the outcome into history.
5. Recompute history summary and optimization suggestions.

## Focus

- average daily return
- realized return
- max drawdown
- win rate
- discipline score
- proportion of off-plan trades
