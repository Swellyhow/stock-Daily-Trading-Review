# Theme Strength Analyzer

Use this skill when the task is to determine whether a theme is a mainline.

## Workflow

1. Read [A股短线情绪交易基础判断标准](/g:/A股游资/游资知识库/A股短线情绪交易基础判断标准-428ca50305.md).
2. For each theme, check:
   - continuity over 2 to 3 days
   - limit-up count rank
   - board ladder integrity
   - whether there is a leader and capacity core
   - next-day profit effect
3. A theme that satisfies 4 of 5 mainline conditions can be marked as `主线`.
4. Downgrade themes that are only first-board follow-ons or lack profit effect.
