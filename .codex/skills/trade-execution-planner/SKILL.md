# Trade Execution Planner

Use this skill when the task is to convert analysis into executable trade setups.

## Workflow

1. Read [A股短线情绪交易每日执行模板](/g:/A股游资/游资知识库/A股短线情绪交易每日执行模板-31c5a5db30.md).
2. Only allow setups already supported by the market stage:
   - 龙头分歧转一致
   - 前排换手板确认
   - 核心股弱转强
   - 主线回流低吸
   - 冰点修复首个试错点
3. Explicitly forbid:
   - 后排跟风追涨
   - 一致加速板盲追
   - 非主线套利
   - 退潮中的中位接力
4. Before any trade, answer the six checklist questions from the source template.
