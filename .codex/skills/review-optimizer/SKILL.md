# Review Optimizer

Use this skill when the task is post-market review and rule refinement.

## Workflow

1. Read [A股短线情绪交易每日执行模板](/g:/A股游资/游资知识库/A股短线情绪交易每日执行模板-31c5a5db30.md).
2. Compare:
   - premarket environment judgment vs actual environment
   - expected mainline vs actual mainline
   - allowed setups vs trades actually taken
3. Record where the system was wrong:
   - threshold problem
   - data quality problem
   - execution discipline problem
4. Prefer updating deterministic rules before adding more complexity.
